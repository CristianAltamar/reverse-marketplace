# Reverse Marketplace

Aplicación móvil para publicar una necesidad de compra, recibir cotizaciones de proveedores locales y elegir una oferta por precio total, disponibilidad, entrega y reputación.

**Estado al 12 de noviembre de 2026.** Documentación inicial v0.1. Reverse Marketplace es el nombre de trabajo. El lanzamiento como app móvil está definido y se propone cubrir Android e iOS. Barranquilla, madera dimensionada y pequeños contratistas son la propuesta de partida que se evaluará con un piloto.

El **primer paso** es reclutar compradores con una compra pendiente y proveedores dispuestos a cotizar. Operar sus primeras solicitudes con un formulario y una plantilla de cotización mientras se prueba el flujo en un prototipo móvil.
