# Reverse Marketplace

Aplicación móvil para solicitar un producto o servicio, recibir cotizaciones de proveedores locales y elegir una oferta por precio total, disponibilidad, plazo y reputación.

**Estado al 12 de noviembre de 2026.** Reverse Marketplace es el nombre de trabajo. El lanzamiento como app móvil está definido y se propone cubrir Android e iOS. El piloto prevé atender solicitudes de distintos rubros en todo Galapa con un grupo reducido de compradores y comercios invitados.

El **primer paso** es reclutar compradores con una compra pendiente y proveedores dispuestos a cotizar. Operar sus primeras solicitudes con un formulario y una plantilla de cotización mientras se prueba el flujo en un prototipo móvil.
