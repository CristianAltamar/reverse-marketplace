# Reverse Marketplace

Aplicación móvil para solicitar un producto o servicio, recibir cotizaciones de proveedores locales y elegir una oferta por precio total, disponibilidad, plazo y reputación.

**Estado al 13 de noviembre de 2026.** Reverse Marketplace es el nombre de trabajo. El lanzamiento como app móvil está definido y se propone cubrir Android e iOS. El piloto asistido cubre todo Galapa con pocos compradores y comercios invitados. La beta móvil tendrá registro abierto y admisión por el equipo.
